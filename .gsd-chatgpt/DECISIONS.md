# SCAP research — durable decisions

## D001 · GSD-inspired ChatGPT process, not full GSD engine (2026-09-30)

Use the installed `bohar-gsd-chatgpt` **skill** to organize inspect → plan → execute → verify → update state. It does not install the official GSD command-line runtime, run headless agents, or schedule work by itself. This directory is project documentation, not an executable agent.

## D002 · Canonical research remains in existing repository (2026-09-30)

`RESEARCH-QUEUE.md`, `sources/SOURCE-REGISTER.md`, `sources/records/`, `SOURCES.md`, `RESEARCH-LOG.md` and English/Tamil/Sinhala topic README files remain authoritative. The GSD plan is an orchestration layer; do not fork financial truth into separate unsourced documents.

## D003 · Source assurance and reporting scope (2026-09-30)

Audited FY2025 SCAP statements and FY2026 year-end **interim** are distinct. The original signed SCAP FY2026 audited annual and June 2026 interim are OPEN until retrieved and reconciled. Sector GWP is not SCAP operating income; group profits include NCI; subsidiary liquidity is not parent cash. Do not fill missing values or silently equate different accounting scopes.

## D004 · Review and execution controls (2026-09-30)

Use focused branches and draft PRs; no auto-merge or production changes. No new GitHub Actions or hosted runners. Existing repository CI can validate the change without authoring workflows. No PDF redistribution absent permission. Existing disabled ChatGPT task remains disabled unless explicitly resumed.

## D005 · Status vocabulary (2026-09-30)

**TEMPLATE:** framework with no sufficiently verified topic-specific evidence. **PARTIAL:** some source-backed SCAP/sector evidence exists but mandatory reconciliation is missing. **FILLED:** the research queue's original-source, legal-scope, language parity, charts and validation checklist is satisfied; it does **not** mean every risk is resolved. Do not retroactively claim all 13 topics are FILLED because an addendum was committed.
