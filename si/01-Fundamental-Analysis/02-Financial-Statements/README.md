## 🎯 ප්‍රධාන පර්යේෂණ ප්‍රශ්නය

## 🔍 රැස් කළ යුතු සාක්ෂි

- [ ] විගණන මතය, ඒකාබද්ධ ආදායම්, මූල්‍ය තත්ත්වය සහ මුදල් ප්‍රවාහ ප්‍රකාශන කියවන්න.
- [ ] SCAP තනි ගිණුම් සමූහ ගිණුම් සමඟ සැසඳී සුළුතර හිමිකම් සහ අනුබද්ධ තැන්පතු වෙනම හඳුනාගන්න.
- [ ] ලාභ, ණය අලාභ වෙන්කිරීම්, නියාමන ප්‍රාග්ධනය, මුදල් ප්‍රවාහ සහ නැවත සකස්කිරීම් ගළපන්න.
