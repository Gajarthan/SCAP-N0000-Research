## 🔍 රැස් කළ යුතු සාක්ෂි

- [ ] දින සහිත මිල සහ නිවැරදි කොටස් ගණන භාවිත කර EPS මව් සමාගමේ හිමියන්ට අයත්දැයි තහවුරු කරන්න.
- [ ] සමාන සමාගම්වල P/E, P/B, ලාභයේ ගුණාත්මකභාවය හා book value එකම අර්ථකථනවලින් සසඳන්න.
- [ ] අනුබද්ධ ආයතනවල වටිනාකම, සුළුතර හිමිකම්, මව් ණය සහ පිරිවැය ඇතුළත් අවස්ථා කිහිපයක මාදිලියක් ගොඩනගන්න.
