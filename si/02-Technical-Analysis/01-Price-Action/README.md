## 🎯 පර්යේෂණ ප්‍රශ්නය

- [ ] corporate actions අනුව මිල සකස්කිරීම්, ගනුදෙනු නොවූ දින හා last trade සහ bid/ask වෙනස පරීක්ෂා කරන්න.
