# 03 · பரிவர்த்தனை அளவு மற்றும் பணமாக்கல் வசதிப் பகுப்பாய்வு

[← தொழில்நுட்பப் பகுப்பாய்வு](../README.md) · [English](../../../02-Technical-Analysis/03-Volume-Liquidity/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/02-Technical-Analysis/03-Volume-Liquidity/README.md)

> **SCAP.N0000 — Softlogic Capital PLC.** **நிலை: இது ஆய்வு வழிகாட்டி மட்டுமே; தற்போதைய trading signal அல்ல.** முதலில் தரவையும் CSE வர்த்தக நாட்களையும் உறுதி செய்யவும். **Reference: 2026-09-30.**

## 🎯 ஆய்வுக் கேள்வி

தேவையான அளவு SCAP பங்குகளைப் பெரிய slippage அல்லது தாமதமின்றி வாங்கவும் விற்கவும் முடியுமா?

## 🔍 சரிபார்க்க வேண்டிய தரவும் முறையும்

- [ ] ஒரே கால இடைவெளிக்கான traded shares, turnover, trade count, வர்த்தகம் இல்லாத நாட்களின் அளவைப் பதிவு செய்யவும்.
- [ ] உண்மையான bid-ask spread, order-book depth, உத்தேச order அளவுக்கான வாங்க/விற்கச் செலவை மதிப்பிடவும்.
- [ ] அதிக volume தோன்றிய நாள் corporate news, free float, block trades தொடர்பு உள்ளதா சரிபார்க்கவும்.

## ⚠️ பொதுவான தவறான முடிவு

காட்டப்படும் அதிக volume அல்லது last traded price உங்களுடைய முழு order-ஐ அந்த விலையில் முடிக்க முடியும் என்று உறுதி செய்யாது.

## 🛠️ SCAP-க்கான நடைமுறை

கிடைத்தால் அதிகாரப்பூர்வ market-depth தரவு பயன்படுத்தவும்; daily volume மட்டும் கொண்டு intraday liquidity என்று கூற வேண்டாம்.
