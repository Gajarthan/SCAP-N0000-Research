# 05 · தொழில்நுட்ப அளவியல் மற்றும் சந்தை மனநிலைப் பகுப்பாய்வு

[← தொழில்நுட்பப் பகுப்பாய்வு](../README.md) · [English](../../../02-Technical-Analysis/05-Quantitative-Sentiment/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/02-Technical-Analysis/05-Quantitative-Sentiment/README.md)

> **SCAP.N0000 — Softlogic Capital PLC.** **நிலை: இது ஆய்வு வழிகாட்டி மட்டுமே; தற்போதைய trading signal அல்ல.** முதலில் தரவையும் CSE வர்த்தக நாட்களையும் உறுதி செய்யவும். **Reference: 2026-09-30.**

## 🎯 ஆய்வுக் கேள்வி

விலை/volume மற்றும் பொது செய்திகளில் காணும் மனநிலையை வெறும் சத்தத்துடன் (noise) குழப்பாமல் எவ்வாறு அளவிடுவது?

## 🔍 சரிபார்க்க வேண்டிய தரவும் முறையும்

- [ ] Price/volume factor, rolling volatility ஆகியவற்றின் கணக்கு, sample, missing data, brokerage செலவு ஆகியவற்றை முன்பே வரையறுக்கவும்.
- [ ] தேதியுள்ள பொது செய்திகள், CSE அறிவிப்புகளைச் சட்டப்படி பயன்படுத்தி sentiment-ஐ உண்மை நிகழ்விலிருந்து பிரிக்கவும்.
- [ ] நீங்கள் தேர்ந்தெடுக்கப் பயன்படுத்தாத புதிய தரவில் எளிய baseline-ஐ விட signal கூடுதல் விளக்கம் தருகிறதா சோதிக்கவும்.

## ⚠️ பொதுவான தவறான முடிவு

Sentiment அடிப்படையில் மட்டுமே technical அல்ல; செய்தி கவனமும் விலை மாற்றமும் correlation-ம் லாபகர signal என்று நிரூபிக்காது.

## 🛠️ SCAP-க்கான நடைமுறை

SCAP-க்கு reproducible data dictionary, event log உருவாக்கி no-trade நாள், look-ahead bias, முரணான செய்திகளைப் பதிவு செய்யவும்.
