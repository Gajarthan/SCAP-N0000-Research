# 04 · வரைபட வடிவங்களும் குறியீடுகளும்

[← தொழில்நுட்பப் பகுப்பாய்வு](../README.md) · [English](../../../02-Technical-Analysis/04-Patterns-Indicators/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/02-Technical-Analysis/04-Patterns-Indicators/README.md)

> **SCAP.N0000 — Softlogic Capital PLC.** **நிலை: இது ஆய்வு வழிகாட்டி மட்டுமே; தற்போதைய trading signal அல்ல.** முதலில் தரவையும் CSE வர்த்தக நாட்களையும் உறுதி செய்யவும். **Reference: 2026-09-30.**

## 🎯 ஆய்வுக் கேள்வி

முன்னைய விலையைப் பார்த்தபின் மனதுக்கு ஏற்ப வரையாமல், chart pattern மற்றும் indicator-களை மற்றவரும் மீண்டும் கணக்கிடும் வகையில் வரையறுக்க முடியுமா?

## 🔍 சரிபார்க்க வேண்டிய தரவும் முறையும்

- [ ] Pattern, breakout threshold, confirmation காலம் ஆகியவற்றின் விதிகளை முடிவைப் பார்க்குமுன் எழுதவும்.
- [ ] Moving averages, RSI, MACD, ATR போன்றவற்றை adjusted OHLCV மற்றும் ஒரே trading-day வரையறையில் கணக்கிடவும்.
- [ ] False breakout, brokerage cost, look-ahead bias, பயனற்ற காலம் ஆகியவற்றையும் சேர்த்துச் சோதிக்கவும்.

## ⚠️ பொதுவான தவறான முடிவு

ஒரு chart-இல் தெரியும் pattern மட்டும் SCAP வருமானத்தை முன்னறிவிக்கிறது என்பதற்குச் சான்றல்ல.

## 🛠️ SCAP-க்கான நடைமுறை

சரியான தரவு, parameter, தோல்வியடைந்த signal, out-of-sample முடிவுகளைத் துல்லியமாகச் சேமிக்கவும்.
