# 02 · போக்கு மற்றும் உந்தப் பகுப்பாய்வு

[← தொழில்நுட்பப் பகுப்பாய்வு](../README.md) · [English](../../../02-Technical-Analysis/02-Trend-Momentum/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/02-Technical-Analysis/02-Trend-Momentum/README.md)

> **SCAP.N0000 — Softlogic Capital PLC.** **நிலை: இது ஆய்வு வழிகாட்டி மட்டுமே; தற்போதைய trading signal அல்ல.** முதலில் தரவையும் CSE வர்த்தக நாட்களையும் உறுதி செய்யவும். **Reference: 2026-09-30.**

## 🎯 ஆய்வுக் கேள்வி

குறிப்பிட்ட கடந்த காலத்தில் SCAP விலை ஒரு அளவிடத்தக்க போக்கோ வேகமோ காட்டுகிறதா?

## 🔍 சரிபார்க்க வேண்டிய தரவும் முறையும்

- [ ] உதாரணமாக 50/200 வர்த்தக நாள் moving average மற்றும் RSI(14) ஆகியவற்றின் வரையறையை எழுதி கணக்கிடவும்.
- [ ] வர்த்தகம் நடக்காத நாள், பழைய close, குறுகிய வரலாறு, corporate action ஆகியவை indicator-ஐ எப்படி பாதிக்கின்றன எனப் பார்க்கவும்.
- [ ] முன்னைய விலைக்கு மட்டும் நன்றாகப் பொருந்தும் parameter-ஐத் தேர்ந்தெடுக்காமல் daily/weekly முறைகளை ஒப்பிடவும்.

## ⚠️ பொதுவான தவறான முடிவு

RSI அளவு, crossover அல்லது uptrend மட்டும் எதிர்காலப் பலனை நிரூபிக்காது.

## 🛠️ SCAP-க்கான நடைமுறை

தரவின் மூலம், தேதி, parameter அனைத்தையும் பதிவு செய்து, சுத்தமான தரவு கிடைத்த பிறகு baseline-உடன் backtest செய்யவும்.
