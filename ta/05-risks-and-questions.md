# 05 — அபாயங்கள் மற்றும் திறந்த கேள்விகள்

**இது அபாயப் பட்டியல்; நிறுவனம் தோல்வியடையும் என்ற முன்னறிவிப்பு அல்ல.**

| அபாயம் | ஏன் முக்கியம்? | பார்க்க வேண்டிய ஆதாரம் |
|---|---|---|
| தாய் நிறுவனக் கடன் | வட்டி மற்றும் கடன் திருப்பிச் செலுத்தல் பங்குதாரர் பணத்தைச் சுருக்கலாம் | தனி நிறுவனக் கடன், உத்தரவாதம், கடன் காலவரை |
| சிறுபான்மை பங்குதாரர்கள் | துணை நிறுவனத்தின் முழு இலாபமும் SCAP-க்கு வராது | உரிமைப் பங்கு, attributable profit |
| காப்பீட்டு அபாயம் | கோரிக்கைகள், வாடிக்கையாளர் தொடர்ச்சி, முதலீட்டு வருமானம் மாறலாம் | Insurance service result, solvency |
| கடன் / வைப்பு அபாயம் | கடன் வசூல் குறைவு அல்லது வைப்பு வெளியேற்றம் | NPL/Stage-3, impairment, liquidity |
| தொடர்புடைய தரப்புகள் | குழுமத்துக்குள் அபாயம்/பணம் நகரலாம் | Related-party குறிப்புகள், அடமானம் |
| சட்ட / ஒழுங்குமுறை மாற்றம் | புதிய மூலதன அல்லது தொழில் கட்டுப்பாடுகள் | CBSL/IRCSL/CSE அறிவிப்புகள் |
| வட்டி / நாணய மாற்றம் | சொத்து வருமானம் மற்றும் கடன் செலவு மாறலாம் | Sensitivity, investment composition |
| பங்கு வர்த்தக அளவு | குறைந்த பரிவர்த்தனையால் விற்கச் சிரமம் இருக்கலாம் | திகதி குறிப்பிடப்பட்ட volume, bid/ask |

**வரலாற்றுக் குறிப்பு மட்டுமே:** [EconomyNext செய்தி](https://economynext.com/sri-lankas-softlogic-finance-to-resume-business-after-central-bank-lifts-restrictions-241534/) படி Softlogic Finance மீதான சில ஒழுங்குமுறை கட்டுப்பாடுகள் **2025-09-19** முதல் நீக்கப்பட்டதாக அறிக்கையிடப்பட்டது. இது இன்று அபாயம் இல்லை என்று நிரூபிக்காது. அசல் CBSL/CSE ஆவணத்தையும் பின்னைய மாற்றங்களையும் சரிபார்க்கவும்.

## முன்னுரிமைக் கேள்விகள்
- [ ] சமீபத்திய தணிக்கையாளர் கருத்து என்ன?
- [ ] தாய் நிறுவன உரிமையாளர்களுக்குரிய இலாபம் எவ்வளவு?
- [ ] தற்போதைய துணை நிறுவன உரிமைப் பங்குகள் எவை?
- [ ] கடன், உத்தரவாதம், பங்குக் கடன் அடமானம் யாரிடம்?
- [ ] அண்மையில் பங்கு வெளியீடு, உரிமை வழங்கல் அல்லது சொத்து விற்பனை இருந்ததா?
- [ ] துணை நிறுவனப் பணம் SCAP-க்கு வந்துள்ளதா?
- [ ] ஒரு தடவை கிடைத்த இலாபமா? தொடரும் இலாபமா?

ஒவ்வொரு பதிலுடனும் **ஆவணம் + தேதி + பக்கம்/குறிப்பு** இணைக்கவும்.
