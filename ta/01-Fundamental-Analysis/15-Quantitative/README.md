> **SCAP.N0000 · Softlogic Capital PLC** · **நிலை:** இது ஆய்வு வழிகாட்டி; SCAP-இன் தற்போதைய முடிவாகக் கருத வேண்டாம். **Reference date: 2026-09-30**.

## 🎯 ஆய்வுக் கேள்வி

கணக்கியல், காலம், தரத் திருத்தங்களைச் செய்த பிறகும் நிறுவனத்தின் புள்ளிவிவர அளவுகோல்கள் உறுதியாக உள்ளனவா?

## 🔎 சரிபார்க்க வேண்டியவை

- [ ] தேதியுள்ள வளர்ச்சி, கடன் இழப்பு, solvency, ROE, valuation எண்களை மீண்டும் உருவாக்கக்கூடிய data table-ஆக அமைக்கவும்.
- [ ] Sample size, விடுபட்ட தரவு, restatement, மாறிய கணக்கியல் வரையறை, ஒருமுறை இலாபம் ஆகியவற்றைச் சோதிக்கவும்.
- [ ] Sensitivity, பகிர்வு மற்றும் சக நிறுவன ஒப்பீடு பயன்படுத்தவும்; correlation-ஐ causation எனக் காட்ட வேண்டாம்.

## ⚠️ ஊகிக்கக்கூடாத விடயம்

ஒப்புச்சரிபார்க்காத ஆண்டு எண்களைக் கொண்டு செய்த சிக்கலான கணக்கு ஆதாரத்தை விட நம்பகமானது அல்ல.

## 🛠️ SCAP-க்கான ஆய்வு

SCAP மற்றும் சக நிறுவன அசல் அறிக்கை வரிகளிலிருந்து தொடங்கி ஒவ்வொரு மாற்றம், denominator, காலம், கருதுகோள் பதிவு செய்யவும்.
