# 03 · பங்கு மதிப்பீட்டுப் பகுப்பாய்வு

[← அடிப்படைப் பகுப்பாய்வு](../README.md) · [English](../../../01-Fundamental-Analysis/03-Valuation/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/01-Fundamental-Analysis/03-Valuation/README.md)

> **SCAP.N0000 · Softlogic Capital PLC**  
> **நிலை:** இது ஆய்வு செய்வதற்கான வழிகாட்டி மட்டுமே; SCAP பற்றிய இறுதி முடிவு இன்னும் உறுதி செய்யப்படவில்லை. **Reference: 2026-09-30**.

## 🎯 முக்கிய ஆய்வுக் கேள்வி

உறுதி செய்யப்பட்ட இலாபம், பங்குகள் எண்ணிக்கை, பணம், மூலதனம், அபாயம் ஆகியவற்றின் அடிப்படையில் எந்த மதிப்பு வரம்பைக் கணக்கிட முடியும்?

## 🔍 சேகரிக்க வேண்டிய ஆதாரங்கள்

- [ ] தேதியுள்ள சந்தை விலையும் சரியான பங்குகள் எண்ணிக்கையும் பயன்படுத்தி EPS தாய் நிறுவன உரிமையாளருக்குரியதா உறுதி செய்யவும்.
- [ ] ஒப்பிடத்தக்க நிறுவனங்களின் P/E, P/B விகிதங்களை இலாப தரம், book value, தொழில் வேறுபாடுகளைச் சரிசெய்து ஒப்பிடவும்.
- [ ] துணை நிறுவனங்களின் தனி மதிப்பு, சிறுபான்மை உரிமை, தாய் நிறுவனக் கடன் மற்றும் செலவுகளுடன் பல சூழல் மாதிரி உருவாக்கவும்.

## ⚠️ தவறாகப் புரிந்துகொள்ளக்கூடிய விடயம்

குறைந்த P/E அல்லது P/B மட்டுமே பங்கு மலிவாக இருக்கிறது என்பதற்குச் சான்றல்ல; தவறான EPS மூலம் எல்லா விகிதங்களும் தவறலாம்.

## 🛠️ SCAP-க்கான அடுத்த ஆய்வு

அசல் attributable profit, உரிமைப் பங்கு, share count, parent-only debt மற்றும் தற்போதைய விலை உறுதி செய்யும்வரை இலக்கு விலை வெளியிட வேண்டாம்.
