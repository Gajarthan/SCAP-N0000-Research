# 01 · வணிகப் பகுப்பாய்வு

[← அடிப்படைப் பகுப்பாய்வு](../README.md) · [English](../../../01-Fundamental-Analysis/01-Business-Analysis/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/01-Fundamental-Analysis/01-Business-Analysis/README.md)

> **SCAP.N0000 · Softlogic Capital PLC**  
> **நிலை:** இது ஆய்வு செய்வதற்கான வழிகாட்டி மட்டுமே; SCAP பற்றிய இறுதி முடிவு இன்னும் உறுதி செய்யப்படவில்லை. **Reference: 2026-09-30**.

## 🎯 முக்கிய ஆய்வுக் கேள்வி

SCAP என்னென்ன நிறுவனங்களை வைத்துள்ளது? அதன் துணை நிறுவனங்களுக்கு வாடிக்கையாளர்கள் எதற்காகப் பணம் செலுத்துகிறார்கள்? SCAP பங்குதாரருக்கு மதிப்பு எவ்வாறு கிடைக்கிறது?

## 🔍 சேகரிக்க வேண்டிய ஆதாரங்கள்

- [ ] ஒவ்வொரு துணை நிறுவனத்தின் சட்டப் பெயர், தேதியுள்ள உரிமைப் பங்கு, வணிகப் பிரிவு மற்றும் சிறுபான்மை பங்கு கண்டறிதல்.
- [ ] காப்பீடு, கடன், தரகு, சொத்து மேலாண்மை ஆகியவற்றின் வருமான-செலவு முறைகளைத் தனித்தனியாக ஆய்வு செய்தல்.
- [ ] இலாபத்தை தாய் நிறுவனத்துக்குப் பகிரக் கூடிய சட்ட மற்றும் மூலதனக் கட்டுப்பாடுகளை அறிதல்.

## ⚠️ தவறாகப் புரிந்துகொள்ளக்கூடிய விடயம்

குழும வருமானம், காப்பீட்டுப் பிரீமியம், AUM ஆகிய அனைத்தும் SCAP சாதாரண பங்குதாரருக்கு உரிய பணம் அல்ல.

## 🛠️ SCAP-க்கான அடுத்த ஆய்வு

SCAP சமீபத்திய அசல் அறிக்கையிலிருந்து தேதியுள்ள உரிமை அமைப்பு வரைந்து segment குறிப்புகளுடன் ஒப்பிடவும்.
