# 04 · தொழில்துறைப் பகுப்பாய்வு

[← அடிப்படைப் பகுப்பாய்வு](../README.md) · [English](../../../01-Fundamental-Analysis/04-Industry/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/01-Fundamental-Analysis/04-Industry/README.md)

> **SCAP.N0000 · Softlogic Capital PLC**  
> **நிலை:** இது ஆய்வு செய்வதற்கான வழிகாட்டி மட்டுமே; SCAP பற்றிய இறுதி முடிவு இன்னும் உறுதி செய்யப்படவில்லை. **Reference: 2026-09-30**.

## 🎯 முக்கிய ஆய்வுக் கேள்வி

காப்பீடு, நிதி, தரகு, முதலீட்டு மேலாண்மை ஆகிய துறைகளின் இலாபத்தை எந்த அமைப்புசார் காரணிகள் தீர்மானிக்கின்றன?

## 🔍 சேகரிக்க வேண்டிய ஆதாரங்கள்

- [ ] உரிமம் பெற்ற நிறுவனங்கள், சந்தை அளவு, வாடிக்கையாளர் தேவை, விற்பனை வழி, புதிய போட்டியாளருக்கான தடைகளை அறியவும்.
- [ ] துறை அளவில் claims, கடன் வளர்ச்சி, வட்டி, capital விதிகள், பொருளாதாரச் சுழற்சி ஆகியவற்றைப் பார்க்கவும்.
- [ ] ஒரே காலம்/வரையறையுடன் துறை வளர்ச்சியையும் தனி நிறுவனச் சந்தைப் பங்கு மாற்றத்தையும் பிரிக்கவும்.

## ⚠️ தவறாகப் புரிந்துகொள்ளக்கூடிய விடயம்

துறை வளர்வதால் எல்லா நிறுவனங்களும் பங்குதாரர்களுக்கு நல்ல வருமானம் தரும் என்று பொருள் அல்ல.

## 🛠️ SCAP-க்கான அடுத்த ஆய்வு

IRCSL, CBSL, CSE ஆகியவற்றின் தேதியுள்ள தரவுகளைக் கொண்டு காப்பீடு, நிதி, சந்தைச் சேவை துறைகளைத் தனியாக ஆய்வு செய்யவும்.
