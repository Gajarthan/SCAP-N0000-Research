# 08 · இடர் பகுப்பாய்வு

[← அடிப்படைப் பகுப்பாய்வு](../README.md) · [English](../../../01-Fundamental-Analysis/08-Risk/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/01-Fundamental-Analysis/08-Risk/README.md)

> **SCAP.N0000 · Softlogic Capital PLC** · **நிலை:** இது ஆய்வு வழிகாட்டி; SCAP-இன் தற்போதைய முடிவாகக் கருத வேண்டாம். **Reference date: 2026-09-30**.

## 🎯 ஆய்வுக் கேள்வி

நிதி, செயல்பாடு, விதிமுறை, நல்லாட்சி மற்றும் பங்குச் சந்தைச் சூழலால் SCAP உரிமையாளரின் மதிப்பு எந்த வழியில் நிரந்தரமாகப் பாதிக்கப்படலாம்?

## 🔎 சரிபார்க்க வேண்டியவை

- [ ] சாத்தியக்கூறையும் பாதிப்பின் அளவையும் வேறுபடுத்தி, ஆதாரமில்லாத இடர் மதிப்பெண் உருவாக்க வேண்டாம்.
- [ ] தாய் நிறுவனக் கடன்/உத்தரவாதம், காப்பீட்டு solvency, கடன் தரம்/வைப்புகள், liquidity, related-party இடர்களைப் படிக்கவும்.
- [ ] ஒவ்வொரு இடருக்கும் நிகழும் சூழல், தடுப்பு, முன்னெச்சரிக்கை அளவு, ஆதாரம் மற்றும் மறுஆய்வு நேரம் பதிவு செய்யவும்.

## ⚠️ ஊகிக்கக்கூடாத விடயம்

இடர் அட்டவணை சாத்தியமான பாதையைக் காட்டும்; சம்பவம் நடந்தது அல்லது கண்டிப்பாக நடக்கும் என்று நிரூபிக்காது.

## 🛠️ SCAP-க்கான ஆய்வு

SCAP இடர் குறிப்புகள், தாய் நிறுவனக் கடன், தற்போதைய ஒழுங்குமுறை அறிவிப்புகளை உறுதி செய்த பிறகே அளவை மதிப்பிடவும்.
