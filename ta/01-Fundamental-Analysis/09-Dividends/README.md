# 09 · இலாபப் பங்கீட்டுப் பகுப்பாய்வு

[← அடிப்படைப் பகுப்பாய்வு](../README.md) · [English](../../../01-Fundamental-Analysis/09-Dividends/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/01-Fundamental-Analysis/09-Dividends/README.md)

> **SCAP.N0000 · Softlogic Capital PLC** · **நிலை:** இது ஆய்வு வழிகாட்டி; SCAP-இன் தற்போதைய முடிவாகக் கருத வேண்டாம். **Reference date: 2026-09-30**.

## 🎯 ஆய்வுக் கேள்வி

குழும இலாபம் இருப்பதற்கு மேலாக, SCAP சாதாரண பங்குதாரர்களுக்கு நிலையாக dividend செலுத்த முடியுமா?

## 🔎 சரிபார்க்க வேண்டியவை

- [ ] கடந்த ஐந்து ஆண்டுகளின் dividend/share, வழங்கிய தேதி, பங்குகள் எண்ணிக்கை, உரிமைக்குரிய இலாப விகிதத்தைப் பார்க்கவும்.
- [ ] துணை நிறுவனங்களில் இருந்து SCAP பெற்ற dividend, தாய் நிறுவனத் தக்கவைத்த இலாபம், பணம், கடன் நிபந்தனைகள் ஆகியவற்றை உறுதி செய்யவும்.
- [ ] காப்பீடு/நிதி நிறுவனங்களின் மூலதன மற்றும் ஒழுங்குமுறை வரம்புகளால் பணப் பங்கீடு கட்டுப்படுகிறதா என்று பார்க்கவும்.

## ⚠️ ஊகிக்கக்கூடாத விடயம்

கடந்தகால அதிக dividend yield எதிர்காலத்திலும் அதே அளவு கிடைக்கும் என்பதற்குச் சான்றல்ல.

## 🛠️ SCAP-க்கான ஆய்வு

அறிவிக்கப்பட்டது, முன்மொழியப்பட்டது, உண்மையில் செலுத்தப்பட்டது என்று பிரித்து, தேதியுள்ள dividend வரலாறும் பணப் பாதையும் தயாரிக்கவும்.
