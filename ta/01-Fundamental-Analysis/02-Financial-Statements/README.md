# 02 · நிதி அறிக்கைப் பகுப்பாய்வு

[← அடிப்படைப் பகுப்பாய்வு](../README.md) · [English](../../../01-Fundamental-Analysis/02-Financial-Statements/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/01-Fundamental-Analysis/02-Financial-Statements/README.md)

> **SCAP.N0000 · Softlogic Capital PLC**  
> **நிலை:** இது ஆய்வு செய்வதற்கான வழிகாட்டி மட்டுமே; SCAP பற்றிய இறுதி முடிவு இன்னும் உறுதி செய்யப்படவில்லை. **Reference: 2026-09-30**.

## 🎯 முக்கிய ஆய்வுக் கேள்வி

தணிக்கை செய்யப்பட்ட வருமானம், சொத்துகள், பொறுப்புகள் மற்றும் பணப்புழக்கம் நிறுவனம் கூறும் வணிக நிலையை ஆதரிக்கிறதா?

## 🔍 சேகரிக்க வேண்டிய ஆதாரங்கள்

- [ ] தணிக்கையாளர் கருத்து, குழும இலாப-நட்டம், இருப்புநிலை மற்றும் பணப்புழக்கத்தை வாசிக்கவும்.
- [ ] SCAP தனி அறிக்கையையும் குழும அறிக்கையையும் ஒப்பிட்டு சிறுபான்மை உரிமை, வைப்புப் பொறுப்புகளைத் தனியாகக் காட்டவும்.
- [ ] ஒரே காலத்திற்கான இலாபம், கடன் இழப்பு ஒதுக்கீடு, மூலதனம், பணப்புழக்கம் மற்றும் திருத்தங்களை ஒப்பிடவும்.

## ⚠️ தவறாகப் புரிந்துகொள்ளக்கூடிய விடயம்

வைப்புகள் நிதி பொறுப்புகள்; காப்பீட்டு வருமானம் gross written premium-க்கு சமமல்ல; குழுமக் கடன் தாய் நிறுவனக் கடன் அல்ல.

## 🛠️ SCAP-க்கான அடுத்த ஆய்வு

FY25/FY26 ஆரம்ப எண்களை ஒவ்வொன்றாக அசல் CSE ஆவணம், பக்கம், அலகு மற்றும் உரிமையாளருக்குரிய இலாபம் ஆகியவற்றுடன் சரிபார்க்கவும்.
