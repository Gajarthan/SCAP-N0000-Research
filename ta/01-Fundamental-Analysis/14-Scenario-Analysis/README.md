# 14 · சூழல் மற்றும் உணர்திறன் பகுப்பாய்வு

[← அடிப்படைப் பகுப்பாய்வு](../README.md) · [English](../../../01-Fundamental-Analysis/14-Scenario-Analysis/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/01-Fundamental-Analysis/14-Scenario-Analysis/README.md)

> **SCAP.N0000 · Softlogic Capital PLC** · **நிலை:** இது ஆய்வு வழிகாட்டி; SCAP-இன் தற்போதைய முடிவாகக் கருத வேண்டாம். **Reference date: 2026-09-30**.

## 🎯 ஆய்வுக் கேள்வி

முதலீட்டு கருதுகோள் மாறினால் விளைவுகள் எவ்வாறு மாறும்? முக்கிய நிச்சயமின்மைகள் என்ன?

## 🔎 சரிபார்க்க வேண்டியவை

- [ ] காப்பீடு, நிதி மற்றும் தாய் நிறுவனப் பணப்பாதைக்கு அடிப்படை, சாதக, பாதக சூழல்களைத் தனித்தனியாக அமைக்கவும்.
- [ ] கடன் இழப்பு, claims, margin, discount rate, தாய் நிறுவனக் கடன், dilution ஆகியவற்றை ஒன்றாகவும் தனித்தனியாகவும் மாற்றிச் சோதிக்கவும்.
- [ ] கருதுகோளின் ஆதாரம், காலம், ஒன்றோடொன்று தொடர்பு, break-even நிலை பதிவு செய்து துல்லியமான ஒற்றை இலக்குக்கு பதில் வரம்பு தரவும்.

## ⚠️ ஊகிக்கக்கூடாத விடயம்

சூழல் கணக்குகள் நிபந்தனை அடிப்படையிலான எடுத்துக்காட்டுகள்; எதிர்கால பங்குவிலை நிகழ்தகவு அல்ல.

## 🛠️ SCAP-க்கான ஆய்வு

உரிமையாளருக்குரிய இலாபமும் தாய் நிறுவன நிதியும் உறுதி செய்யப்பட்ட பிறகு மட்டுமே ஆதாரமுள்ள sensitivity grid உருவாக்கவும்.
