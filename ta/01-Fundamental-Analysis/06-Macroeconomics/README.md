# 06 · பேரினப் பொருளாதாரப் பகுப்பாய்வு

[← அடிப்படைப் பகுப்பாய்வு](../README.md) · [English](../../../01-Fundamental-Analysis/06-Macroeconomics/README.md) · [தமிழ்](README.md) · [සිංහල](../../../si/01-Fundamental-Analysis/06-Macroeconomics/README.md)

> **SCAP.N0000 · Softlogic Capital PLC**  
> **நிலை:** இது ஆய்வு செய்வதற்கான வழிகாட்டி மட்டுமே; SCAP பற்றிய இறுதி முடிவு இன்னும் உறுதி செய்யப்படவில்லை. **Reference: 2026-09-30**.

## 🎯 முக்கிய ஆய்வுக் கேள்வி

இலங்கை வட்டி, பணவீக்கம், நாணய மதிப்பு, கடன் தேவை, முதலீட்டு சூழல் ஆகியவை SCAP வணிகங்களை எவ்வாறு பாதிக்கலாம்?

## 🔍 சேகரிக்க வேண்டிய ஆதாரங்கள்

- [ ] CBSL வட்டி விகிதம், பணவீக்கம், கடன் வளர்ச்சி ஆகியவற்றை வெளியீட்டுத் தேதியுடன் பதிவு செய்யவும்.
- [ ] வட்டி மாற்றம் நிதி நிறுவனச் சொத்து/பொறுப்புகளையும் காப்பீட்டு முதலீடுகளையும் வேறுபட எவ்வாறு பாதிக்கும் எனச் சோதிக்கவும்.
- [ ] நாணய மாற்றம், குடும்ப வருமானம், பங்குச் சந்தை வர்த்தகம் ஆகியவற்றின் உண்மையான exposure-ஐ அறிக்கைகளில் கண்டறியவும்.

## ⚠️ தவறாகப் புரிந்துகொள்ளக்கூடிய விடயம்

வட்டி உயர்வு/குறைவு தானாகவே நல்லது அல்லது கெட்டது அல்ல; சொத்து மற்றும் கடன் மறுவிலை நிர்ணய நேரங்கள் மாறலாம்.

## 🛠️ SCAP-க்கான அடுத்த ஆய்வு

'குறியீடு → பாதிக்கும் பிரிவு → காரணம் → ஆதாரம் → எதிர் சான்று' என்ற தேதியுள்ள அட்டவணை உருவாக்கவும்.
