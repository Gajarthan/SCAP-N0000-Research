**ஆதாரக் குறியீடுகள்:** **உறுதி — நிறுவனம்** = நிறுவனம் வெளியிட்ட குறிப்பிட்ட, தேதியுள்ள தகவல் (சுயாதீன உறுதி அல்ல); **இரண்டாம் நிலை** = மூன்றாம் தரப்புத் தகவல்; **கருதுகோள்** = சோதிக்க வேண்டிய விளக்கம்; **இன்னும் திறந்தது** = கூடுதல் சான்று தேவை.
