## 🎯 Research question

How do investment assumptions change outcomes, and which variables dominate uncertainty?

## 🔎 What to verify

- [ ] Model separately plausible base, optimistic and adverse assumptions for insurer, finance and parent cash distributions.
- [ ] Vary key inputs one at a time and together: credit loss, claims, margins, discount rates, holding-company debt and dilution.
- [ ] Document assumption sources, time horizon, dependencies and break-even conditions; report ranges rather than false precision.
