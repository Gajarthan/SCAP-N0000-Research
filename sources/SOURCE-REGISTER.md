## Source priority and exception handling

1. **Issuer or regulator original** for historical and current claims; separate SCAP group/parent/insurer/finance accounts.
2. **Audited vs interim:** carry the report's exact audit status, not the fact that an annual-report web index lists a later document.
3. **Secondary websites:** use only for lead generation and comparisons; note any different definitions and date windows.
4. **Unavailable or unverified original:** keep original URL and report/document status `OPEN`, never invent PDF pages, values or a SHA-256.
5. **Documents that may be mirrored:** only place a binary in `sources/documents/` after confirming the right to reproduce it publicly and successfully writing its exact bytes; record SHA-256, bytes, downloaded UTC date, publisher's licence and confirmed repository link in the record. If a lawful file download or binary GitHub write is unavailable, keep the external original. Never place passwords, brokerage statements, cookies, paid feeds, personal holdings or private customer information in this public repo.
6. Each research task adds **one record per distinct original**, avoiding duplicate PDFs across English/Tamil/Sinhala, and links by stable source ID into the report evidence table.
7. Source links are **not themselves verification** that an original PDF has been viewed page-by-page. Review the relevant original content for every materially used assertion.
